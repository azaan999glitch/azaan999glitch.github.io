## Fun Marriage Certificate Generator

This is a playful web app built with React and Vite that lets you generate a fun, unofficial marriage certificate! Enter two names, a date, and a location, and the app will create a whimsical certificate you can share for laughs.

## Features
- Enter names, date, and location
- Instantly generate a playful marriage certificate
- Create as many certificates as you like

## Getting Started

### Install dependencies
```
npm install
```

### Start the development server
```
npm run dev
```
Open your browser to the local address shown in the terminal (usually http://localhost:5173/).

## Usage
1. Fill in the names, date, and location.
2. Click "Generate Certificate".
3. View and share your fun marriage certificate!
